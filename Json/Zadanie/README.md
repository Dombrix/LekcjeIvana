# Jak zacząć

To pliki startowe do zadania „Lista zgłoszeń z JSON”, po slajdach 1-67 kursu JS.
HTML jest gotowy. Uzupełnij TODO w app.js i dane.json według karty zadania.
Pusty dane.json oraz brak działania programu przed wykonaniem TODO są celowe.

W tym folderze otwórz terminal:

```powershell
python -m http.server 8000
```

Otwórz http://127.0.0.1:8000/. Jeżeli port jest zajęty, użyj 8001 i zmień
adres na http://127.0.0.1:8001/. Serwer zatrzymasz Ctrl+C.
To zwykły JavaScript, więc nie używasz kompilatora TypeScript ani npm.
Konsolę i żądania sprawdzisz w F12: Console i Network.

Po wykonaniu zadania uzupełnij raport.md. Oddaj cały folder i zrzuty ekranu.
